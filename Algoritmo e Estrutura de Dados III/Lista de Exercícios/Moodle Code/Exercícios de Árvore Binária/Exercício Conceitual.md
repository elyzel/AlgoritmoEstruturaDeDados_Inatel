1. O número de níveis de uma árvore binária quase completa com 40 nós é:
Select one:

 - [ ]  nda

- [ ] 4

- [x] 6

- [ ]  3

 - [ ] 5

## **Resposta:**

A fórmula para calcular o número máximo de nós até determinado nível é:

$$N = 2^{p+1}-1$$

Onde:

- \(N\) = quantidade máxima de nós.
    
- \(p\) = último nível da árvore.

Como o resultado é igual a 31, é necessário ter mais um nível para alcançar um valor alcance o valor de 40 nós.

$$ 2^4 - 1 = 15 ✕$$  
$$ 2^5 - 1 = 31✕$$

$$ 2^5 - 1 = 63✓$$

4. Selecione a afirmação que contém uma afirmação falsa.

Select one:

- [x] Uma árvore quase completa de profundidade p sempre tem folhas nos níveis p e p-1.
- [ ] Em uma árvore quase completa, todos os nós têm sempre zero ou dois filhos.
- [x] Uma árvore estritamente binária de profundidade p pode ter folhas desde o nível 1 até o nível p.
- [x] Em uma árvore binária, quando há elementos repetidos, estes são sempre inseridos como filhos direitos.
- [x] Uma árvore estritamente binária pode ser quase completa.

`Falsa`
